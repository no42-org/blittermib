# AGENTS.md

Self-hosted SNMP MIB browser. Go + libsmi + SQLite/FTS5 + templ/HTMX.

## Commands

```bash
make generate        # regenerate *_templ.go — REQUIRED after editing .templ
make verify          # fmt-check + vet + race tests (the CI gate)
make lint            # golangci-lint
make build
go test ./internal/store -run TestName -race   # a single test
```

`make verify` needs libsmi **0.5.0+** on PATH (`make check-tools`). The
Ubuntu-packaged 0.4.8 hits "internal error" on a chunk of the corpus —
CI builds 0.5.0 from source for the MIB-validation workflow.

## Architecture

MIB files → `internal/compile` (subprocesses `smidump`/`smilint`, parses
the XML) → `internal/model` (normalised types) → `internal/store` (SQLite
schema + FTS5, transactional reload) → `internal/server` (routes, JSON
API, embedded assets) rendering `internal/web` templ templates.
`internal/watch` drives fsnotify hot-reload on the corpus directory.

Side paths worth knowing: `internal/correlate` infers notification
raise/clear/orphan relationships; `internal/eventconf` exports OpenNMS
eventconf; `internal/walk` decodes pasted snmpwalk captures;
`internal/mibimport` is the contributor drop-folder pipeline behind
`make ingest`; `internal/mcptools` is the shared read-only tool set for
both MCP transports.

## Gotchas

- **CSS source of truth is `prototype/styles.css`**, not
  `internal/server/assets/styles.css` — that one is generated by `make
  prepare-assets`. CI fails on drift. Same for `*_templ.go` vs `.templ`.
- `mibs/INDEX.yaml` is generated by `make index`; CI checks it for drift
  when a PR touches `mibs/**`.
- The local `mibs/` corpus is a subset. Full-corpus behaviour only
  reproduces on the deployed instance — don't conclude "not found" from
  a local miss alone.
- Walk captures are parsed in memory and must never be logged or
  persisted. Keep it that way.
- `internal/iana/pen.txt` is a curated snapshot refreshed by a quarterly
  workflow, not fetched at runtime.
